# atomno-mcp-erid

Проверка **формата** токена маркировки рекламы (erid): длина и допустимые символы. В закрытый реестр ЕРИР запрос не ходит — база доступна РКН/ФАС. Разбор рекламной страницы и пакетная проверка ещё не подключены.

Ad-marking MCP: erid token format check. No ERIR registry lookup.

[![Glama](https://img.shields.io/badge/Glama-listed-7c3aed.svg)](https://glama.ai/mcp/servers/atomno-mcp/mcp-erid)

> Инструмент — **читалка формата**, не проверка по реестру. Ответ **не юридическое
> заключение**; ответственность за маркировку по 38-ФЗ несёт
> **рекламодатель / рекламораспространитель**.

## Что умеет сейчас

- Принимает токен erid и сообщает, прошёл ли он проверку формата (в коде клиента/сервера: длина 8–64, латиница, цифры, дефис, подчёркивание).
- На публичном адресе сейчас все тулы, включая проверку формата, отвечают `ready: false` — «источник ещё подключается».
- Не ищет токен в ЕРИР и не утверждает, что размещение зарегистрировано.

## Что не подключено

- Реестр ЕРИР (закрыт)
- Разбор рекламной страницы (пометка «Реклама», данные рекламодателя)
- Пакетная проверка списка URL
- Живой чек-лист 38-ФЗ по странице

## Быстрый старт

```bash
pipx install atomno-mcp-erid
# или: uvx atomno-mcp-erid
```

Cursor / Claude Desktop (`mcp.json` / `claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "erid": {
      "command": "uvx",
      "args": ["atomno-mcp-erid"]
    }
  }
}
```

Разовые тулы принимают запрос без ключа. Для `audit_batch` нужен `MCP_ERID_API_KEY`.

## Переменные окружения

| Переменная | Описание | Обязательна |
|---|---|---|
| `MCP_ERID_API_KEY` | Ключ Pro для `audit_batch`. [Получить](https://atomno-mcp.ru/pricing#erid-pro) | нет (только для Pro-тула) |
| `MCP_ERID_API_BASE` | URL hosted-бэкенда (по умолчанию — прод) | нет |
| `MCP_ERID_TIMEOUT` | Таймаут HTTP, сек (default 30) | нет |
| `MCP_ERID_LOG_LEVEL` | Уровень логирования (DEBUG/INFO/WARNING/ERROR, default WARNING) | нет |

## Тулы

| Тул | Вход | Что отвечает сейчас |
|---|---|---|
| `verify_erid` | erid | на живом адресе `ready: false`; в коде — проверка формата, не реестр |
| `audit_ad_page` | url | `ready: false` — разбор страницы не подключён |
| `check_compliance_38fz` | has_ad_label?, has_advertiser_info?, erid?, url? | `ready: false` — чек-лист по живой странице не подключён |
| `explain_marking_requirement` | topic | на живом адресе `ready: false`; в коде есть краткая справка по темам |
| `audit_batch` | urls[] | `ready: false` — пакетная проверка не подключена |

Каждый ответ содержит `source`, `checked_at` и `disclaimer`.

## Дисклеймер

Полная база **ЕРИР закрыта** (доступ у РКН/ФАС) и не проверяется. Ответ носит
**справочный** характер и **не является юридическим заключением**. Не
аффилировано с ЕРИР, ОРД, РКН или ФАС.
